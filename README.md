# 修行日课

每天的功课清单：勾一项划一项，早上 5 点自动开始新的一天，每天的打卡都记下来。

线上地址：https://xiangshu3721.github.io/xiuxing-rike/

## 清单
1. 三清理断舍离（清理环境 / 清理身体和情绪 / 清理信息&关系&想法&念头）——三项一组，点组标题可一键全勾/全取消
2. 10 遍忏悔咒
3. 天气预报觉察（2026-10-06 起）
4. 打坐🧘‍♂️
5. 晒太阳

共 7 个可勾项。清单写在 `app.js` 顶部的 `CHECKLIST` 数组里，增改项目只改这里（每项的 `id` 定了就别改，历史记录靠它对应）。
完成数、全勤、连续天数、月历深浅一律按“当天生效的清单”计算：新加的项写 `since: 'YYYY-MM-DD'`，那天之前的日子不算这一项（「天气预报觉察」从 2026-10-06 起，之前的日子按 6 项算）；v1.3 去掉了独立的「断舍离」（id `duansheli`），旧日子里它的打卡记录仍保存在数据和导出文件里，但不再显示、不参与计数；旧日子只要做完当时那几项就算全勤。

「10 遍忏悔咒」旁边有「看经文」，点开是《忏悔文》手写图（`img/chanhui.jpg`）和八句简体文字；点它不会打卡。经文配置在 `app.js` 的 `SCRIPTURES` 里，清单项写 `scripture: 'chanhui'` 即可关联。

「今天」页清单下方有一段低调的提醒（师门警示，小字浅墨色、无底色），只做展示，不影响打卡，也不进分享图。

「清理身体和情绪」旁边有「回春叩问↗」，直接打开《回春明点叩问》（https://xiangshu3721.github.io/huichun/）；手机和微信里在当前页打开，返回后打卡状态还在，电脑上开新标签。清单项写 `link: { text, href }` 即可加外链。

## 规则
- **一天的分界是早上 5:00（本地时间）**：凌晨 5 点前还算前一天，方便熬夜；过了 5 点打开就是新的一天、全部未勾。页面一直开着也会自动换天（每 15 秒检查一次，切回页面时也会检查）。
- **连续全勤**：当天生效的清单（现在是 7 项）全部勾完算全勤一天。今天还没做完不算断，过了第二天早上 5 点还没做完才断。
- 页面、历史详情、分享图都不显示完成时间（早上做、晚上统一打勾也没关系）；内部仍保留勾选时的时间戳，导出数据里有。

## 分享图
「今天」页右上角「保存图片」，或在「打卡记录」里点开某一天 →「保存这一天的图片」，会用 Canvas 在本机生成一张 1080 宽的竖版图：日期和星期，下面直接**只列已经完成的项**（三清理断舍离组里有完成的子项才显示组；不显示完成时间），全勤日带「圆满」金印；连续全勤 ≥ 2 天时清单下方有一行淡淡的小字；0 项的日子只显示一句温和的话。（应用页面里的进度显示不变。）图片高度随项数自适应。
保存方式：电脑和安卓 Chrome 等支持下载的浏览器，点按钮直接下载 PNG（提示「已保存到下载」，不弹预览）；iPhone（Safari 和主屏模式）、微信、不支持下载的浏览器会弹出预览，长按图片保存（iPhone Safari 还可点「下载图片」在新页面打开图片）。

## 数据
- 只存在本机浏览器的 localStorage（key：`xiuxing-rike.v1`），没有登录、没有后端。
- 「打卡记录」里可以导出 JSON 备份、导入备份（和现有记录合并，同一项保留更早的完成时间）、清空（需要二次确认）。

## 发布新版本
改了 `style.css` / `app.js` 等资源后，把 `index.html`、`manifest.webmanifest`、`app.js`（经文图片）里的 `?v=` 和 `sw.js` 里的 `VERSION`、资源列表一起改成新版本号。页面本身走“网络优先”，不会卡在旧版本。

纯静态页面，GitHub Pages 从 `main` 分支根目录发布。
