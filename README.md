# 修行日课

每天的功课清单：勾一项划一项，早上 5 点自动开始新的一天，每天的打卡都记下来。

线上地址：https://xiangshu3721.github.io/xiuxing-rike/

## 清单
1. 三清理断舍离（清理周围环境和能量场 / 清理身体和自己物品、信息 / 清理内心和情绪；v1.11 改名，id 不变）——三项一组，点组标题可一键全勾/全取消；组标题右侧有「查看」（v1.11 起），点开看断舍离说明
2. 天气预报觉察（2026-10-06 起；v1.8 起移到忏悔咒上面，要「记录」才算完成）
3. 10 遍忏悔咒
4. 自定义任务（v1.12 起）：默认是「打坐」（名字旁有打坐小人图标）和「晒太阳」，可以改名、删除、调顺序、新增

1～3 是**固定项**：不能删、不能改名、永远排在最前面，「查看」「回春叩问」「记录」「看经文」照旧；写在 `app.js` 顶部的 `CHECKLIST` 数组里（每项的 `id` 定了就别改，历史记录靠它对应）。默认共 7 个可勾项。

## 自定义任务（v1.12）
- **入口**：今天页清单底部的「＋ 管理任务」（虚线小药丸，点击区 ≥ 44px）。弹层上半部分灰色列出固定项，带小锁「默认」标签，不能编辑；下半部分是自定义任务，每项右侧有 ↑ / ↓（调顺序，第一项不能上移、最后一项不能下移）、「改名」（就地变成输入框，Enter 保存、Esc 取消）、「删除」（就地二次确认「删除「X」？从今天起不再计入，以前的打卡记录都保留。」）。底部输入框 +「添加」新建任务。×、点遮罩、Esc 关闭弹层。手机优先，320 宽可用。
- **校验**（新增和改名都一样）：去掉首尾空格后 1～20 个字；不能和现有任务重名（固定项、组名「三清理断舍离」、其它没删除的自定义任务都算，大小写不敏感），提示「请输入任务名称」「名称最多 20 个字（现在 N 个字）」「已经有「X」了，换个名字吧」。自定义任务最多 20 个。
- **自定义任务排在固定项后面**，顺序就是管理弹层里的顺序；今天页、历史详情、30 天统计、分享图都按这个顺序。
- **打坐图标**：名字里有「打坐」两个字的任务旁边画打坐小人（改成「打坐 30 分钟」还在，改成「静坐」就没了，新增的「打坐…」也会有）。
- **全勤文案**按当天实际项数用中文数字说，如「七项圆满」「八项圆满」（2 项说「两项」，0 项不会说「零项圆满」，换成普通的一句）。

### 数据兼容
- 存在同一个 localStorage key 的新字段 `tasks` 里：`[{ id, title, since?, until?, at? }]`，数组顺序即显示顺序。旧数据没有这个字段时，第一次打开自动迁移成 `[{ id: 'dazuo', title: '打坐' }, { id: 'shaitaiyang', title: '晒太阳' }]`，id 不变，所以历史打卡、连续天数完全不受影响。
- **新增**：id 为 `custom-时间戳`，`since` = 添加那天（按 5 点分界）。之前的日子不算这一项，不会因为新增任务变成未全勤；添加当天起才计入（当天已全勤的话，新任务没勾就暂时不算全勤）。
- **删除**：不删任务记录、不删打卡数据，只记 `until` = 删除那天，从那天起不再计入；删除之前的日子仍按当时的清单算完成数、全勤、连续天数，历史详情和分享图也照样显示那天有的这一项。当天新增又当天删除的任务从没生效过，直接拿掉（打卡数据仍留着）。
- **改名**：只改 `title`，id 不变；历史上的日子也显示新名字。
- 某一天的清单 = 固定项（带 `since` 的从那天起）+ `since ≤ 那天 < until` 的自定义任务。
- **导出**的 JSON 多一个 `tasks`（含已删除的，用于按当时清单算历史）。**导入**：旧备份没有 `tasks` 就保持本机清单不动；有的话按 id 合并——本机没有的任务加到后面，两边都有时以 `at`（最后修改时间）较新的为准；固定项的 id、不合格的条目忽略。
- 「清空记录」只清打卡记录，自定义任务清单保留。
完成数、全勤、连续天数、月历深浅一律按“当天生效的清单”计算：新加的项写 `since: 'YYYY-MM-DD'`，那天之前的日子不算这一项（「天气预报觉察」从 2026-10-06 起，之前的日子按 6 项算）；v1.3 去掉了独立的「断舍离」（id `duansheli`），旧日子里它的打卡记录仍保存在数据和导出文件里，但不再显示、不参与计数；旧日子只要做完当时那几项就算全勤。

「10 遍忏悔咒」旁边有「看经文」，点开是《忏悔文》手写图（`img/chanhui.jpg`）和八句简体文字；点它不会打卡。经文配置在 `app.js` 的 `SCRIPTURES` 里，清单项写 `scripture: 'chanhui'` 即可关联。

「天气预报觉察」旁边有「记录」（和「看经文」同款）。这一项**不能直接勾**：点勾选框、项名或「记录」都会打开记录弹层，三项都必填——**天气**（手动写，1～50 字，自动去掉首尾空格）、**压力**（1～10 分）、**能量**（1～10 分），压力和能量是左右拖动的滑杆（1～10，步长 1；压力暖金、能量墨绿，上方大字实时显示数值，两端有「1 / 10」提示；触屏点哪跳到哪、横向拖动跟手，竖向滑动不算选）。新建时两条滑杆是「未选择」（数值显示「—」、滑块淡色），拖动、点按或用方向键动过才算选了；编辑时回显已存的值。没写全时保存不了，会提示还缺哪一项；保存后这一项自动打勾。已完成后再点可以查看和修改（修改不改变完成状态）；弹层里的「清除今天的觉察」要二次确认，确认后取消完成并删掉内容。完成后清单这一项下面有一行淡色小字，如「晴，微风 · 压力 6 · 能量 7」（太长最多两行、省略号），不显示时间。历史详情、分享图（这一项下面附一行小字）里也有这行内容。「打卡记录」里有「近 30 天压力和能量」小折线（没记的日子断开）和平均值。清单项写 `record: true` 即为这种「记录后完成」的项（目前只有这一项）。v1.8 之前直接勾过的日子仍算完成，只是没有内容，可以点开补记或清除。

「打坐」名字旁有一个打坐小人图标（v1.9.1 起；v1.12 起名字里有「打坐」的自定义任务都画）：自绘线条（实心头、两手搭膝、盘腿），墨绿色，约一个字高；今天页、历史详情、近 30 天统计用内联 SVG，分享图用 Canvas 画同一份路径，所以 iPhone、安卓、微信里样子一致，不依赖系统 emoji。分享图里仍只在打坐勾选了时才有这一行。图标配置在 `app.js` 的 `ICONS`，固定清单项写 `icon: 'dazuo'` 即可。（v1.0～v1.9.0 名字里是 🧘‍♂️ emoji，页面上靠系统 emoji 显示，分享图从 v1.1 起一直把 emoji 去掉了，所以图上没有。）

「今天」页清单下方有一段低调的提醒（师门警示，小字浅墨色、无底色），只做展示，不影响打卡，也不进分享图。

「三清理断舍离」组标题右侧有「查看」（v1.11 起，和「看经文」「记录」同款小按钮，点击区 ≥ 44px，和右边的「x/3」并排不挤），点它只弹出说明、不会触发全勾；说明复用看经文的弹层（不带图片），×、点遮罩、Esc 都能关。内容照原文：

> **断**：断掉无益之烦恼　**舍**：放舍执念与妄念　**离**：远离负能量
> **早上**：清理周围环境和能量场　**下午**：清理自己和自己物品　**晚上**：清理内心

只在今天页有；分享图、历史详情里没有这个按钮。文字配置在 `app.js` 的 `INFOS`，清单项或分组写 `info: 'xxx'` 即可。

「清理内心和情绪」旁边有「回春叩问↗」（v1.11 起从原来的「清理身体和情绪」那条移过来），直接打开《回春明点叩问》（https://xiangshu3721.github.io/huichun/）；手机和微信里在当前页打开，返回后打卡状态还在，电脑上开新标签。清单项写 `link: { text, href }` 即可加外链。

## 打卡日历（v1.10）
「打卡记录」里的月历**默认收起**，只显示一行「打卡日历 · 10月 · 打卡 N 天 · 全勤 M 天　展开 ⌄」；点这一行展开 / 收起（动画轻柔）。展开状态不记住：每次打开应用或切到「打卡记录」都是收起的。收起不影响下面的当天详情、各项统计、30 天折线图。
- **切月**：头部「‹」「›」按钮；手机上在月历上左右滑动也能切（明显的水平滑动才算，竖向滚动不受影响，滑动时手指下的日子不会被点中）。不能翻到未来月份（在本月时「›」变灰）；往前不设下限（最早到 2000 年 1 月），没记录的月份也能看。
- **选年月**：点标题「2026年10月」弹出年月选择：左右切年份，12 个月格子，未来月份灰掉，有打卡的月份右上角有个小金点；选中即跳转并展开月历。
- **回到本月**：不在本月时，标题下面出现「回到本月」小按钮；年月选择里也有。
- 统计卡片里的「本月全勤（天）」跟着所选月份变（如「9月全勤（天）」，跨年显示「2025年12月全勤（天）」）；连续全勤、最长连续是全局的，不变。点任一历史日照常看当天详情；按条目生效日期计算的规则不变。

## 规则
- **一天的分界是早上 5:00（本地时间）**：凌晨 5 点前还算前一天，方便熬夜；过了 5 点打开就是新的一天、全部未勾。页面一直开着也会自动换天（每 15 秒检查一次，切回页面时也会检查）。
- **连续全勤**：当天生效的清单（现在是 7 项）全部勾完算全勤一天。今天还没做完不算断，过了第二天早上 5 点还没做完才断。
- 页面、历史详情、分享图都不显示完成时间（早上做、晚上统一打勾也没关系）；内部仍保留勾选时的时间戳，导出数据里有。

## 分享图
「今天」页右上角「保存图片」，或在「打卡记录」里点开某一天 →「保存这一天的图片」，会用 Canvas 在本机生成一张 1080 宽的竖版图：日期和星期，下面直接**只列已经完成的项**（三清理断舍离组里有完成的子项才显示组；不显示完成时间），右上角盖一枚随机印章（v1.9 起；v1.10 起不论完成几项、包括 0 项都盖，见下）；连续全勤 ≥ 2 天时清单下方有一行淡淡的小字；0 项的日子只显示一句温和的话。（应用页面里的进度显示不变。）图片高度随项数自适应。
**随机印章**：每次生成分享图（今天页「保存图片」、历史「保存这一天的图片」）都盖，并且都重新随机——词、样式、颜色、角度各自独立随机，不存储；v1.10 起不再要求全勤，部分完成和 0 项的图也盖（「连续全勤」那行小字仍按原规则只在连续 ≥ 2 天时出现）。
- 词库（`app.js` 的 `STAMP_WORDS_ZH` / `STAMP_WORDS_EN`，共 56 个）：中文最多两个字（两个字竖排、一个字居中放大）——真棒、优秀、牛、坚持、圆满、精进、厉害、给力、漂亮、满分、超棒、加油、好样、稳、赞、自在、清净、善哉、功成、不错、威武、了得、欢喜、安然、甚好、妙、绝了、很强、出色、完美、极好、赞叹、喜乐、光明、吉祥、如意、有恒、心安、日新、精彩、帅、好极；英文单个短词、最多 6 个字母（横排斜体衬线，字号按印面宽度自适应，上下两道细线）——Nice、Good、Great、Cool、Wow、Yes、Bravo、Super、Top、Yay、Neat、Ace、Epic、Bingo。
- 样式（`STAMP_SHAPES`）：双线方章、圆章（双圈）、椭圆章、圆角方章、白文实底（色底米白字）、八角章（双线）；角度 -15° ~ +12° 随机；印面撒米白小点做旧（印泥不均），不挡字。
- 颜色（`STAMP_COLORS`）：朱砂 #b5382a、暖金 #a9823a、墨绿 #3f5e4f、靛青 #2e4a6b、赭石 #9a5a2e、胭脂 #a03650、紫檀 #6b3a3a。
- 页面上没有印章（只在分享图里）。

保存方式：电脑和安卓 Chrome 等支持下载的浏览器，点按钮直接下载 PNG（提示「已保存到下载」，不弹预览）；iPhone（Safari 和主屏模式）、微信、不支持下载的浏览器会弹出预览，长按图片保存（iPhone Safari 还可点「下载图片」在新页面打开图片）。

## 数据
- 只存在本机浏览器的 localStorage（key：`xiuxing-rike.v1`），没有登录、没有后端。
- 每天一条：`days['YYYY-MM-DD'] = { items, done: { 项id: 勾选时间戳 }, updatedAt, juecha }`。v1.8 新增可选字段 `juecha: { weather, stress, energy, at }`（`at` 是最后保存时间，只存不显示）；「天气预报觉察」是否完成仍只看 `done['tianqi-juecha']`，其他字段含义不变。
- v1.12 新增顶层字段 `tasks`（自定义任务，见上）。
- 「打卡记录」里可以导出 JSON 备份（含觉察内容和自定义任务）、导入备份（和现有记录合并，同一项保留更早的完成时间；觉察内容本机没有就用备份的，两边都有保留最后保存的那份，不合格的内容忽略；没有 `juecha` 的旧备份照常导入）、清空（需要二次确认）。

## 发布新版本
改了 `style.css` / `app.js` 等资源后，把 `index.html`、`manifest.webmanifest`、`app.js`（经文图片）里的 `?v=` 和 `sw.js` 里的 `VERSION`、资源列表一起改成新版本号。页面本身走“网络优先”，不会卡在旧版本。

纯静态页面，GitHub Pages 从 `main` 分支根目录发布。
